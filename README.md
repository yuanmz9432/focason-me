# focason-me

The personal website of Yuan Mingze, built with Vue 3 and Vite.

## Development

```sh
pnpm install
pnpm run dev
```

## Production build

```sh
pnpm run build
pnpm run preview
```

The production output is written to `dist/`. An `amplify.yml` build definition is included for deployment with AWS Amplify Hosting.
